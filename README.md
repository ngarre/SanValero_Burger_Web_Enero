# San Valero Burger Contest Web

## Descripción
Aplicación web interactiva desarrollada con React que permite explorar un listado de food trucks y sus hamburguesas. Ofrece funcionalidades de filtrado por nombre o ingredientes (con coincidencia parcial), por tipo (vegana o cárnica) y por rango de precio, mostrando los resultados en orden ascendente o descendente.

## Tecnologías utilizadas
- React + TypeScript
- Vite
- React Router DOM
- API REST (Spring Boot)
- HTML5 / CSS3
- Git y GitHub

## Funcionalidades principales
- Consumo de datos desde dos endpoints de una API REST
- Navegación mediante React Router con rutas dinámicas
- Filtrado, búsqueda y ordenación en tiempo real
- Vista de detalle de food trucks y hamburguesas
- Diseño responsive
- Optimización y rendimiento: imágenes en formato WebP, CSS minificado, carga diferida (lazy loading)

## Puesta en marcha del proyecto
```bash
npm install
npm run dev
```
